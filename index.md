<dd>The Dutch Institute for Vulnerability Disclosure (DIVD) provides details on September 29 AI agent cyberattack, which possibly exploited a chain of two zero-day vulnerabilities in open-source ticketing system, Zammad. <dt>September 28, 2026</dt>
<dd>Microsoft discloses June 2026 Azure cyberattack by AI-driven, agentic threat actor group, JADEPUFFER (or Storm-3168). Storage accounts, Azure Key Vault, Function Apps, and SQL databases were targeted; the threat actor took 7 minutes to get to them. The objective appeared to be destruction, rather than data exfiltration. Source: <a href="https://aviatrix.ai/threat-research-center/jadepuffer-azure-tenant-destructive-cloud-attack-2026/" target="_blank">Aviatrix</a></dd>
<dt>September 23, 2026</dt>
<dd>Gambit security researchers document a deployment of AI agents (combining Strix, Cairn, Hermes) by financially motivated attackers. The numbers: 5 days, 105 attack waves, 119+ retail sites, 600,000+ credit card records. Source: <a href="https://www.bleepingcomputer.com/news/security/malicious-ai-agents-steal-600k-credit-cards-infect-100-plus-sites-with-skimmers/" target="_blank">Bleeping Computer</a></dd>
<dt>September 22, 2026</dt>
<dd>Security researcher Patrick Wardle discovers a zero-day vulnerability in Meta's Muse AI assistant that allows adversaries to access authentication tokens via ClickFix attack. This grants full control over the agent and the resources it has permission to access (e.g., email, banking integrations). Source: <a href="https://arstechnica.com/security/2026/09/muse-metas-extraordinarily-privileged-ai-assistant-has-a-serious-0-day/" target="_blank">Ars Technica</a></dd>
